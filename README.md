# Mammography Lesion Detection

This project demonstrates lesion detection on mammography images using YOLOv8 and the VinDr-Mammo dataset.

## Dataset
- VinDr-Mammo (PhysioNet)
- Bounding box annotations for lesion detection

## Method
- YOLOv8 object detection model
- Training and inference performed on a subset of the dataset
- Images resized to 640x512

## Results
Example predictions from the trained model are provided in this repository.
Some test images do not contain lesions, therefore no bounding boxes are predicted.

## Notes
This repository is prepared as part of a research laboratory application.
